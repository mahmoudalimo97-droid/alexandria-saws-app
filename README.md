# 👑 كاتلوج أسعار شركة الإسكندرية للمناشير وآلات الألوميتال والـ UPVC

تطبيق ويب تقدمي (PWA) فائق السرعة والبساطة، مخصص لعرض أسعار ومواصفات ماكينات ومناشير الألوميتال والـ UPVC لعملاء الورش والمصانع.

- 📱 **متوافق 100% مع الموبايل**: تصميم هادئ وأنيق بلونين فقط (`#0F3B4C` مع الأبيض)، وبطاقات واضحة وأزرار لمس سريعة.
- ⚡ **تطبيق أوفلاين بالكامل (PWA)**: يعمل بدون إنترنت فور فتحه لأول مرة مع خط Tajawal مدمج محلياً دون أي اعتماد خارجي.
- 🚀 **نشر تلقائي على GitHub Pages**: مبني بـ Vite + React ويعتمد على GitHub Actions لنشر وتحديث الموقع تلقائياً بمجرد عمل `git push`.
- 🔒 **خفيف وآمن**: بدون أي سيرفر خلفي (Backend) وبدون أي مفاتيح API؛ جميع البيانات في ملف واحد سهل التعديل `src/data.ts`.

---

## 📋 دليل الرفع والنشر على GitHub Pages خطوة بخطوة

### الخطوة 1: إنشاء مستودع جديد على GitHub
1. سجّل الدخول إلى حسابك على [GitHub](https://github.com/).
2. اضغط على زر **New** أو **Create repository**.
3. اكتب اسم المستودع (مثال: `alex-saws-catalog`).
4. اختر المستودع **Public** (أو Private إذا كان لديك اشتراك Pro).
5. **لا تُحدد** (Do NOT check) خيارات: `Add a README file` أو `.gitignore` أو `license`، لأنها موجودة بالفعل في المشروع.
6. اضغط **Create repository**.

---

### الخطوة 2: رفع ملفات المشروع من جهازك
افتح الطرفية (Terminal أو Git Bash) داخل مجلد المشروع، ونفّذ الأوامر التالية:

```bash
# 1) تهيئة Git
git init

# 2) إضافة جميع الملفات (بما فيها package-lock.json و .github)
git add .

# 3) حفظ التغييرات
git commit -m "Initial commit: Alexandria Saws PWA Catalog"

# 4) تسمية الفرع الأساسي main
git branch -M main

# 5) ربط المستودع برابط مستودعك على GitHub (استبدل USERNAME و REPO-NAME ببياناتك)
git remote add origin https://github.com/USERNAME/REPO-NAME.git

# 6) رفع الملفات
git push -u origin main
```

---

### الخطوة 3: تفعيل النشر التلقائي عبر GitHub Actions
1. في صفحة مستودعك على GitHub، اضغط على تبويب **Settings** (الإعدادات).
2. من القائمة الجانبية على اليسار، اضغط على **Pages**.
3. تحت قسم **Build and deployment**:
   - ستجد قائمة **Source**: غيّر الخيار من `Deploy from a branch` إلى **`GitHub Actions`**.
4. بمجرد اختيار **GitHub Actions**، سيبدأ البناء تلقائيًا عبر ملف الـ Workflow الموجود في `.github/workflows/deploy.yml`.

---

### الخطوة 4: متابعة البناء والحصول على الرابط
1. انتقل إلى تبويب **Actions** في مستودعك.
2. ستشاهد سير العمل باسم **Deploy to GitHub Pages** قيد التنفيذ (علامة صفراء تدور).
3. بعد دقيقة أو دقيقتين ستتحول إلى علامة صح خضراء ✅.
4. اضغط على العملية وستجد رابط موقعك جاهزاً ومباشراً:
   ```
   https://USERNAME.github.io/REPO-NAME/
   ```

## 📲 كيفية تثبيت التطبيق على الموبايل (PWA)

### لأجهزة أندرويد (Google Chrome):
1. افتح رابط الموقع في متصفح كروم.
2. ستظهر لك رسالة وشريط بالأعلى: **"تثبيت الكاتلوج على هاتفك"** -> اضغط **"تثبيت التطبيق"**.
3. أو اضغط على قائمة الثلاث نقاط في المتصفح (⋮) ثم اختر **"تثبيت التطبيق"** أو **"إضافة إلى الشاشة الرئيسية"**.
4. سيظهر تطبيق الكاتلوج كأيقونة مستقلة على هاتفك بدون شريط المتصفح ويعمل حتى في وضع الطيران بدون إنترنت.

### لأجهزة آيفون (Apple Safari):
1. افتح رابط الموقع في متصفح Safari.
2. اضغط على زر **المشاركة** (الأيقونة ذات المربع والسهم لأعلى ⎋) في الشريط السفلي.
3. مرّر لأسفل واضغط على **"إضافة إلى الشاشة الرئيسية" (Add to Home Screen)**.
4. اضغط على **إضافة (Add)** في الزاوية العلوية.

## ✏️ كيفية تعديل وتحديث الأسعار والبيانات

جميع بيانات الكاتلوج مجمعة داخل ملف واحد سهل القراءة:
👉 `src/data.ts`

### 1) تعديل سعر ماكينة أو منشار:
ابحث عن اسم الماكينة داخل مصفوفة `PRODUCTS` وعدّل الأرقام:
```ts
{
  id: 'saw-thomas-18',
  name: 'منشار توماس 18 بوصة',
  newPrice: 32500, // السعر الحالي الجديد
  oldPrice: 35000, // السعر قبل الخصم (اجعله 0 لو مفيش خصم)
  hot: true,       // علامة عرض خاص
}
```

### 2) تعديل أرقام الهواتف أو العنوان:
عدّل كائن `COMPANY_INFO` في بداية الملف:
```ts
export const COMPANY_INFO = {
  name: 'شركة الإسكندرية للمناشير وآلات الألوميتال والـ UPVC',
  primaryPhone: '01229455338',
  whatsappNumber: '201229455338',
  location: 'الإسكندرية – المندرة – بجوار قسم ثالث المنتزه',
  // ...
};
```

### 3) نشر التعديل تلقائيًا:
بعد حفظ التعديل، نفّذ:
```bash
git add src/data.ts
git commit -m "Update prices: March 2026"
git push
```
ستقوم GitHub Actions بإعادة البناء فوراً، وسيظهر للمستخدمين شريط: **"يوجد تحديث جديد للأسعار - اضغط للتحديث"**.

## 🛠️ استكشاف الأخطاء الشائعة وحلها (Troubleshooting)

1. **ظهور شاشة بيضاء (White Screen 404):**
   - تأكد من أنك اخترت **Source = GitHub Actions** في إعدادات GitHub Pages وليس `Deploy from branch`.
   - تأكد من أن المسار التلقائي في الـ workflow مضبوط مع اسم المستودع (مضبوط بالفعل كـ `/${{ github.event.repository.name }}/`).

2. **فشل أمر `npm ci` في GitHub Actions:**
   - تأكد من رفع ملف `package-lock.json` ضمن مستودعك، فالأمر `npm ci` يتطلب وجود هذا الملف بدقة.

3. **الخطوط أو الصور لا تظهر عند انقطاع الإنترنت:**
   - خط **Tajawal** بأوزانه (400, 500, 700) مدمج بالكامل محلياً بصيغة `.woff2` داخل المشروع ومحفوظ في الكاش بواسطة الـ Service Worker.
   - الصور والصفحات تُخزن تلقائياً فور أول زيارة لموقع الكاتلوج.
